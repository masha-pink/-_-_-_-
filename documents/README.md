## Введение

Целью проектной практики являлась разработка дизайн-проекта музея украшений в историческом здании Нижнего Новгорода (ул. Рождественская, 40) с последующим созданием веб-сайта для презентации результатов. В задачи практики входило: изучение мировых музейных аналогов, анализ ограничений объекта культурного наследия (ОКН), формирование экспозиционной концепции «Кабинет путешественника», создание статического сайта на HTML/CSS, освоение инструментов Git и Markdown, а также подготовка итогового отчёта.

Практика проходила в период с 03 февраля 2025 г. по 24 мая 2025 г. под руководством куратора от кафедры «Информатика и информационные технологии».

---

## 1. Общая информация о проекте

- **Название проекта:**  
  Разработка музейно-выставочной экспозиции для частного музея (рабочее название: «Светлица»).

- **Цели и задачи проекта:**  
  **Цель** – создать современное музейное пространство в здании – объекте культурного наследия, где коллекция традиционных украшений разных народов экспонируется в атмосфере старинного кабинета коллекционера-путешественника.  
  **Задачи:**  
  1. Провести анализ аналогов (Музей Фаберже, V&A London, Лувр Абу-Даби, Van Cleef & Arpels, Эрмитаж).  
  2. Разработать планировочные решения для 9 залов (Китай, Йемен, Индия, Иранское нагорье, Африка+Венеция, Болгария, Мастерская, Офис, Хранилище).  
  3. Предложить типы витрин и климатических систем с учётом сохранности экспонатов.  
  4. Внедрить мультимедийные решения (сенсорные киоски, AR-примерку, тактильные 3D-копии, направленный звук).  
  5. Создать статический веб-сайт для презентации проекта.  
  6. Подготовить полную документацию в репозитории GitHub.

## 3. Описание задания по проектной практике

Задание состояло из **обязательной** (создание сайта-презентации на HTML/CSS) и **вариативной** (разработка дизайн-проекта музея) частей.

**Обязательная часть:**  
- Изучить синтаксис Markdown и вести всю документацию в этом формате.  
- Создать статический веб-сайт (не менее 5 страниц), включающий:  
  * домашнюю страницу с аннотацией;  
  * страницу «О проекте» с подробным описанием;  
  * страницу «Участники» с указанием личного вклада;  
  * страницу «Журнал» с минимум тремя постами о прогрессе;  
  * страницу «Ресурсы» со ссылками на полезные материалы.  
- Оформить сайт с помощью HTML и CSS, обеспечить адаптивность и разместить на GitHub Pages.

**Вариативная часть:**  
- Провести анализ существующих музеев украшений.  
- Предложить концепцию экспозиции для здания ОКН на ул. Рождественской, 40.  
- Разработать планировку 9 залов, типы витрин и климатические системы.  
- Подобрать мультимедийное оборудование.  
- Сформулировать требования по пожарной безопасности и доступности для маломобильных групп.

**Дополнительные исследования (выездные мероприятия):**  
В рамках вариативной части я и другие участники команды **посетили ювелирные выставки в Москве** («Ювелирный вернисаж», экспозиции Гохрана), чтобы изучить реальные приёмы подсветки и размещения украшений. Кроме того, мы **ездили в Нижний Новгород** для осмотра самого здания на ул. Рождественской, 40 – сделали замеры, оценили состояние исторических стен и потолков, сфотографировали архитектурные детали. Без этих поездок проектные решения не были бы адаптированы к реальному объекту.

## 4. Описание достигнутых результатов по проектной практике

### 4.1. Веб-сайт (HTML/CSS)
- Создан статический сайт из 5 страниц (`index.html`, `about.html`, `team.html`, `journal.html`, `resources.html`) с единым файлом стилей `style.css`.  
- Дизайн выполнен в стиле «Обитель сокровищ» (цвета: состаренный пергамент, тёмное дерево, золотистые акценты).  
- Реализована адаптивная вёрстка, сайт корректно отображается на компьютерах и мобильных устройствах.  
- В журнал внесены три записи о ключевых этапах проекта.  
- Сайт опубликован через GitHub Pages (ссылка добавлена в репозиторий).

### 4.2. Документация в Markdown и Git
- Создан репозиторий на GitHub с файлами: `README.md`, `task/README.md`, `journal.md`, `report.md`.  
- Изучен синтаксис Markdown (заголовки, списки, таблицы, ссылки, вставка изображений).  
- Настроена структура папок, выполнены коммиты с осмысленными сообщениями.

### 4.3. Дизайн-проект музея
- Разработана концепция «Кабинет путешественника» с разбиением на 9 залов.  
- Для каждого зала определены: основные экспонаты, тип витрин, цветовое решение, мультимедийное сопровождение.  
- Предложены технические решения:  
  * **Витрины:** комбинация низких горизонтальных (Van Cleef) и вертикальных отдельно стоящих (Эрмитаж), а также индивидуальные витрины для топ-5 предметов.  
  * **Климат-контроль:** автономные модули MicroClimate Pro для драгоценностей, пассивные системы для органических материалов.  
  * **Освещение:** трековое акцентное + внутривитринная LED-подсветка с CRI>90, цветовая температура 2700-3000K.  
- Подобрано мультимедийное оборудование: планшеты Infinix XPAD 20 для сенсорных киосков, капсульная кофеварка Tuvio TCM04EA для зоны отдыха, система направленного звука («звуковой купол»).  
- Разработаны сценарии для интерактивных панелей (Карта Шёлкового пути, «Азбука орнамента», «Собери украшение»).  
- Подготовлены требования по пожарной безопасности (ширина проходов ≥1,2 м, не менее 2 выходов для залов с 50+ посетителями).

### 4.4. Личный вклад и приобретённые навыки
- **HTML и CSS** – научилась верстать многостраничный сайт, работать с флексбоксами, подключать шрифты, создавать карточки команды и журнал прогресса.  
- **Markdown и Git** – освоила ведение документации в репозитории, работу с коммитами и GitHub Pages.  
- **Исследовательская работа** – проанализировала более 10 музейных аналогов, участвовала в поездке в Нижний Новгород, посещала выставки в Москве.  
- **Командная работа** – распределяла задачи с другими участниками (дизайнерами, инженерами мультимедиа), синхронизировала результаты через общий репозиторий.
